Why

반복되는 WinForms UI를 재사용 가능한 컨트롤로 분리

색상 선택, 체크 목록, 대량 그리드처럼 반복되는 WinForms UI를 컨트롤로 분리해 화면 코드 중복을 줄였습니다.

Controls

구성 컨트롤

README 캡처로 각 컨트롤의 핵심 동작을 빠르게 볼 수 있습니다.

ColorComboBox

색상 팔레트를 드롭다운으로 열고 선택 색상을 사각형으로 표시합니다.

CheckBoxComboBox

체크박스 목록을 드롭다운으로 보여주는 다중 선택 콤보박스입니다.

CheckableGroupBox

체크 상태에 따라 내부 컨트롤을 활성화하거나 비활성화합니다.

DoubleBufferedDataGridView

많은 행을 표시할 때 깜빡임을 줄이도록 더블 버퍼링을 적용했습니다.

VerticalFlowLayoutPanel

세로 방향 배치와 스크롤 사용에 맞춘 FlowLayoutPanel입니다.
